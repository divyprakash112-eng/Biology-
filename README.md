# NEET AARAMBH — Biology Test Series 2027

Static GitHub Pages website for the Biology Test Series.

## Features

- 50 scheduled tests
- 32 chapter-wise tests
- 8 cumulative mixed tests
- 10 full-syllabus mocks
- 10 AM–10 PM IST live window
- Countdown to the next scheduled test
- Search and filters
- Per-test syllabus popup
- Planner PDF link
- CBT HTML availability checks
- Responsive mobile-friendly design
- No backend or login required

## GitHub Pages deployment

1. Create a separate Biology repository.
2. Upload all files to the repository root.
3. Keep index.html at the root.
4. Open Settings → Pages.
5. Select the main branch and / (root).
6. Save and wait for deployment.

## CBT files

Upload the CBT HTML files using the exact paths
defined in assets/js/tests.js.

Example:

tests/test-01.html
tests/test-02.html
tests/test-03.html

## Schedule

Timezone: Asia/Kolkata

Live starts: 10:00 AM IST

Live ends: 10:00 PM IST

Upcoming tests stay locked in the website interface.
Uploaded previous tests remain available for practice.

## Important

The schedule lock is browser-side only. GitHub Pages
does not protect public CBT URLs from direct access.

Strict access control requires server-side enforcement.

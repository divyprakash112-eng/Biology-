# NEET AARAMBH Biology CBT Files

Upload standalone CBT HTML files into this folder.

Required naming:

- test-01.html
- test-02.html
- test-03.html
- ...
- test-50.html

Keep the filenames exactly the same as those defined in
assets/js/tests.js.

Do not upload PCB Combined test files here by mistake.

Each CBT must include its required HTML, CSS, JavaScript
and images, or use correct relative asset paths.

A test will remain unavailable until its CBT HTML file
has been uploaded.
